# 一、项目概述

## 1.1 项目背景

在软件产品与创业项目的早期阶段，很多人脑海中只有零散的痛点、需求与奇思妙想，却难以将它们整合为一份结构清晰、可落地的项目规划。传统的方案策划依赖经验与时间成本，门槛较高。

随着大语言模型（LLM）能力的成熟，AI 可以在极短时间内理解碎片化输入、补全缺失逻辑，并输出结构化、专业的规划文档。本项目正是基于这一背景，打造一款"创意雏形合成助手"，让每个人都能低成本地把灵感变成可执行的雏形方案。

## 1.2 项目定位

「创意雏形合成助手」是一款面向产品经理、创业者、开发者与创意爱好者的 AI Web 应用。用户只需输入三类碎片信息——**痛点、需求、奇思妙想**，系统即可通过 AI 整合收拢、补全逻辑，生成完整的项目雏形规划。

## 1.3 项目目标

1. 提供**工具创新（软件开发规划）**与**创业创新（创业项目规划）**两种生成模式；
2. 支持**流式输出**，让 AI 生成过程可视化、体验更自然；
3. 支持**方案迭代**，基于现有方案上下文持续优化；
4. 提供**评论交流**与**个人方案管理**，形成完整的创作闭环；
5. 具备完整的**用户认证体系**，保障数据安全与私有性。

## 1.4 核心价值

- **降低门槛**：无需专业背景，输入碎片即可获得专业规划；
- **提升效率**：从想法到雏形方案，从数小时压缩到数秒；
- **结构化输出**：统一、专业、可执行的方案框架；
- **持续进化**：支持迭代优化与社区交流，让创意不断生长。

## 1.5 技术亮点

- Next.js 14 App Router 全栈架构，前端页面与后端 API 一体化；
- Vercel AI SDK + DeepSeek API 实现服务端流式输出；
- Prisma + SQLite 轻量数据库，零部署成本；
- bcryptjs + jose JWT + HttpOnly Cookie 安全认证；
- Framer Motion 动效 + shadcn/ui 组件，体验与颜值兼备。
