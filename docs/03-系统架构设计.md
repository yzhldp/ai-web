# 三、系统架构设计

## 3.1 整体架构

本项目采用 **Next.js 14 App Router 全栈架构**，前后端一体化部署，无需独立后端服务。

```
┌─────────────────────────────────────────────────────┐
│                     浏览器 (Client)                   │
│  React 组件 + Framer Motion + Tailwind + shadcn/ui   │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP / 流式 (SSE)
┌──────────────────────▼──────────────────────────────┐
│                  Next.js 14 (Server)                 │
│  ┌─────────────┐  ┌──────────────┐  ┌─────────────┐ │
│  │  页面路由    │  │  API 路由     │  │  中间件      │ │
│  │  (RSC)      │  │  (Route API) │  │ (鉴权)      │ │
│  └─────────────┘  └──────┬───────┘  └─────────────┘ │
│                          │                            │
│  ┌─────────────┐  ┌──────▼───────┐  ┌─────────────┐ │
│  │  认证模块    │  │  AI 模块      │  │  数据访问层  │ │
│  │  (jose/bcrypt)│ │ (AI SDK)     │  │  (Prisma)   │ │
│  └─────────────┘  └──────┬───────┘  └──────┬──────┘ │
└───────────────────────────┼─────────────────┼────────┘
                            │                 │
                 ┌──────────▼─────┐   ┌───────▼───────┐
                 │  DeepSeek API  │   │  SQLite 数据库 │
                 │  (外部 LLM)     │   │  (单文件)      │
                 └────────────────┘   └───────────────┘
```

## 3.2 技术选型

| 类别 | 技术 | 选型理由 |
| --- | --- | --- |
| 框架 | Next.js 14 | 全栈一体化、App Router、RSC、流式支持 |
| 语言 | TypeScript | 类型安全、可维护性 |
| 样式 | Tailwind CSS | 原子化、快速开发 |
| UI | shadcn/ui + lucide-react | 高质量可定制组件、图标丰富 |
| 动画 | Framer Motion | 声明式动画、交互流畅 |
| 数据库 | SQLite | 单文件、零运维 |
| ORM | Prisma | 类型安全、Schema 即文档、迁移管理 |
| 认证 | bcryptjs + jose | 密码加密 + JWT，轻量安全 |
| AI | Vercel AI SDK + DeepSeek | 统一流式接口、成本低、中文友好 |

## 3.4 数据模型（Prisma Schema）

## 3.5 安全设计

1. **密码安全**：bcryptjs 加盐哈希存储，不保存明文；
2. **认证机制**：jose 签发 JWT，写入 HttpOnly Cookie（防 XSS 窃取）；
3. **路由鉴权**：中间件拦截受保护页面，未登录跳转登录页；
4. **接口鉴权**：API 层二次校验用户身份与资源归属；
5. **密钥管理**：环境变量注入，`.env` 不入库，提供 `.env.example` 模板。
