# 五、核心功能实现

## 5.1 用户认证

### 5.1.1 密码加密

使用 `bcryptjs` 对密码进行加盐哈希（盐值轮数 10），数据库仅存储哈希值。

### 5.1.2 JWT 签发与校验

使用 `jose` 库签发 HS256 签名的 JWT，payload 携带用户 `uid`，有效期 7 天。密钥从 `JWT_SECRET` 环境变量读取。

### 5.1.3 Cookie 存储

登录/注册成功后，将 JWT 写入 **HttpOnly Cookie**（`httpOnly: true`），前端脚本无法读取，防止 XSS 攻击窃取 token。

### 5.1.4 路由鉴权中间件

`src/middleware.ts` 拦截受保护页面（`/home`、`/tool`、`/business`、`/profile`、`/plans`），校验 Cookie 中的 JWT：

- 未登录访问受保护页面 → 重定向 `/login`；
- 已登录访问 `/login` → 重定向 `/home`。

## 5.2 方案生成（流式输出）

核心流程位于 `src/components/plan-workspace.tsx`：

1. 用户填写痛点、需求、奇思妙想三个输入框；
2. 点击「创新合成」，前端组装为结构化 user 消息；
3. 请求 `/api/chat`（`action=generate`），逐块读取纯文本流并实时 `setContent`；
4. 流结束后，调用 `POST /api/plans` 将方案自动保存到当前账号；
5. 右侧通过 `react-markdown` + `remark-gfm` 渲染结构化方案。

## 5.3 方案迭代

- 用户在底部补充需求，点击「发送」；
- 前端请求 `/api/chat`（`action=iterate`），并携带当前方案内容作为 `context`；
- 服务端将当前方案注入系统提示词，输出更新后的完整方案；
- 完成后调用 `PATCH /api/plans/[id]` 更新数据库中的方案内容。

## 5.4 评论交流

- `src/components/comment-section.tsx` 组件根据当前 `planId` 加载评论（`GET /api/comments?planId=`）；
- 发布评论调用 `POST /api/comments`，成功后追加到列表；
- 评论展示用户头像（首字母）、昵称/账号、内容、时间。

## 5.5 个人方案管理

- `src/components/profile-view.tsx` 通过 `GET /api/plans?mode=` 分别加载工具类与创业类方案；
- 支持查看详情（弹窗展示完整 Markdown 方案）、删除（`DELETE /api/plans/[id]`）；
- 昵称修改调用 `PATCH /api/auth/me`。

## 5.6 悬浮创意助手

- `src/components/floating-assistant.tsx` 提供可拖拽的卡通悬浮球「创意小蓝」，位置写入 localStorage，刷新后保持；
- 拖拽使用 Pointer Events + `setPointerCapture`，并区分「点击展开」与「拖动」，兼容鼠标与触屏；
- 内置 `src/lib/assistant-faq.ts` 本地意图库，覆盖使用步骤、功能、模式区别、安全、RAG、质检、迭代、导出、模型切换等常见问题；
- 未接入 AI 或 AI 调用失败时，仍可回答本地 FAQ 并执行「跳转到工具创新 / 创业创新 / 个人主页」；
- 未命中本地意图时请求 `POST /api/assistant`，返回简洁回答；解析 `[[NAV:xxx]]` 标记后自动跳转；
- 面板跟随悬浮球位置展开，并显示 AI 在线 / 离线状态点。

## 5.7 登录页漫画动画

`src/components/comic-character.tsx` 使用 Framer Motion keyframes 数组 + `times` 实现 6 秒循环动画：

1. 三个气泡「痛点」「需求」「奇思妙想」依次冒出；
2. 气泡向中间移动聚合，合并为「项目雏形」大气泡；
3. 灯泡图标点亮并产生发光动效（`drop-shadow` 滤镜）；
4. 循环重置播放。
