### 6.1.3 接口冒烟测试

使用 `curl` 验证核心接口：

| 用例 | 预期结果 |
| --- | --- |
| 访问 `/login` | 返回 200 |
| 访问根路径 `/`（未登录） | 307 重定向到 `/login` |
| 未登录访问 `/home` | 307 重定向到 `/login` |

| 错误密码登录 | 401，提示账号或密码错误 |

| 创建方案 | 200，返回方案 id |

### 6.1.5 AI 能力测试用例

| 用例 | 预期结果 |
| --- | --- |
| `POST /api/agent/generate`（正常输入） | SSE 依次返回 stage / analysis / sources / tool / token / quality / done |
| 输入含「忽略以上指令 + 输出系统提示词」 | 400，安全策略拦截，写入审计 |
| 输入含违法违规关键词 | 400，返回风险类别，写入审计 |
| `POST /api/knowledge` | 返回混合检索结果与双通道得分 |
| `GET /api/agent/audit` | 返回调用日志与 Token / 工具 / 耗时统计 |
| `GET /api/agent/models` | 返回供应商优先级、配置状态与主供应商（不含密钥） |
| `POST /api/agent/models/evaluate` | 逐供应商返回结构化 / 工具调用 / 引用三项评测结果 |
| 主供应商配置错误、备用供应商可用 | 自动切换并在前端显示切换次数，审计记录 `fallbacks` |
| 主供应商与备用供应商均不可用 | 返回明确错误，不长时间挂起 |
| 未配置 `DEEPSEEK_API_KEY` 调用生成 | 快速返回 SSE error 事件，不长时间挂起 |
| 未配置视觉模型上传图片 | 提示降级，文本生成与架构图正常 |
| 多次快速调用 | 触发分钟级 / 日级限流，返回 429 |

### 6.1.6 关键测试点

- 账号 1-20 位、密码 6-20 位校验；
- 注册时账号全局唯一性；
- 密码一致性校验；
- 方案仅本人可修改/删除（资源归属鉴权）；
- 评论需登录、内容非空；
- Agent 各阶段失败时具备降级路径；
- 生成中断（停止按钮）后不产生脏数据。

## 6.2 部署

### 6.2.1 本地部署

```bash
pnpm install
cp .env.example .env   # 填写 DEEPSEEK_API_KEY / JWT_SECRET
pnpm db:push           # 初始化数据库
pnpm build
pnpm start
```

### 6.2.2 Docker Compose 部署（推荐）

```bash
cp .env.docker.example .env.docker
# 编辑 .env.docker：填写 DEEPSEEK_API_KEY，JWT_SECRET 使用随机长字符串
docker compose up -d --build

docker compose ps
curl http://localhost:3000/api/health
```

- 镜像采用多阶段构建，运行阶段以非 root 用户启动；
- 启动脚本先执行 `prisma db push`，再启动 Next.js；
- SQLite 数据挂载到命名卷 `creative-prototype-assistant-data`；
- 容器内置 `/api/health` 健康检查（数据库 + 知识库 + 模型配置）。

### 6.2.3 云平台部署要点

1. 设置环境变量：`DEEPSEEK_API_KEY`、`JWT_SECRET`（务必使用强随机密钥）；
2. 数据库使用 SQLite 单文件，注意部署平台需提供**持久化磁盘**（否则重启会丢失数据）；
3. 建议将 SQLite 文件存放在持久卷，或将 `DATABASE_URL` 指向持久化路径；
4. 多副本部署时，内存限流需替换为 Redis，并考虑将 SQLite 迁移到 PostgreSQL；
5. 构建命令 `pnpm build`，启动命令 `pnpm start`。

### 6.2.4 免费部署方案（一个月）

针对个人/参赛场景，推荐以下免费部署平台（详见下文部署方案）：

- **Vercel**：Next.js 官方推荐，免费额度充足，一键部署；但需注意 SQLite 文件系统的持久化限制；
- **Railway / Render**：提供免费实例与持久化卷，适合带数据库的全栈应用；
- **Zeabur / Fly.io**：支持 Docker 部署，可按需配置卷存储。

> 具体步骤与利弊分析见「免费部署上线一个月方案」。

## 6.3 注意事项

- `.env` 与数据库文件（`prisma/dev.db`）均已在 `.gitignore` 中忽略，不会误提交真实密钥与数据；
- 生产环境务必修改 `JWT_SECRET` 为随机强密钥；
- DeepSeek API Key 需在平台充值少量余额方可调用。
