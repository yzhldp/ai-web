# 九、评审体验指南

本文档面向评审老师与体验者，说明三种运行方式、评审获取 AI 能力的两种路径，以及未配置密钥时的可用范围。

---

## 一、三种运行方式（按省事程度排序）

| 方式 | 需要安装 | 首次耗时 | 适用场景 |
| --- | --- | --- | --- |
| A. 离线运行包（Windows x64） | 无 | 解压后约 10 秒 | 评委本地电脑无 Node / Docker |
| B. Docker Compose | Docker Desktop | 1-3 分钟（本地构建） | 已有 Docker 环境 |
| C. 源码一键脚本 | Node.js 18.17+ | 3-5 分钟 | 需要对源码评审或二次开发 |

### 方式 A：离线运行包

1. 解压 `ai-web-offline-win-x64.zip` 到任意目录（路径不含中文和空格）
2. 双击「启动.bat」
3. 浏览器自动打开 http://localhost:3000

包内已内置 Node.js、全部生产依赖与预生成的数据库，无需联网即可打开页面。数据库已预置永久测试账号与演示项目、评论数据，解压后可直接登录。

### 方式 B：Docker Compose

```bash
cp .env.docker.example .env.docker
docker compose up -d --build
```

首次运行会在本地构建镜像，之后直接启动即可。容器启动时会先同步数据库结构，再确保永久测试账号存在，并按 `SEED_DEMO_DATA` 初始化演示数据。

### 方式 C：源码一键脚本

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

```bash
# macOS / Linux
sh scripts/start-local.sh
```

脚本会自动安装依赖、初始化数据库，并创建永久测试账号；默认同时写入演示项目与评论（`SEED_DEMO_DATA=false` 时只创建测试账号）。

### 登录账号

| 类型 | 账号 | 密码 | 说明 |
| --- | --- | --- | --- |
| 永久测试账号 | `test` | `test1234` | 离线包已预置；Docker / 一键脚本启动时自动确保存在，适合评审与自动化验收 |
| 演示账号 | `linxiaoman` / `chenyiming` / `suqing` / `zhouye` | `demo1234` | 带公开项目、评论、点赞与收藏，适合体验社区功能 |

## 二、AI 功能如何启用

AI 能力由服务端读取模型密钥后启用，密钥不会出现在前端。项目内置 DeepSeek、通义千问、智谱 GLM、Kimi、豆包、文心一言、腾讯混元、讯飞星火、MiniMax、阶跃星辰、零一万物、百川、商汤、硅基流动等国内主流平台，以及本地 Ollama，按优先级自动故障转移。

> 安全原则：公开仓库中只保存 `.env.example` 模板，`.env` 与 `.env.docker` 已被 `.gitignore` 忽略，任何真实密钥都不进入版本库。

### 评审获取 AI 能力的两种路径

| 路径 | 评委需要做什么 | 密钥存放位置 | 适用场景 |
| --- | --- | --- | --- |
| A. 自备免费密钥 | 注册智谱账号，填 4 行配置 | 评委本机 `.env` | 本地离线包 / Docker 运行，零成本 |
| B. 演示专用密钥 | 解压即用，无需注册 | 随包分发的 `.env`（不进入仓库） | 希望评委完全不接触注册流程 |

#### 路径 A：评委自备免费密钥（零成本）

智谱 GLM-4-Flash 永久免费，注册地址 https://open.bigmodel.cn ，创建 API Key 后写入环境变量：

```env
ZHIPU_API_KEY="你的智谱key"
ZHIPU_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
ZHIPU_MODEL="glm-4-flash"
AI_PROVIDER_ORDER="zhipu"
```

| 运行方式 | 配置文件 | 生效方式 |
| --- | --- | --- |
| 离线运行包 | 解压目录下的 `.env` | 关闭窗口后重新双击「启动.bat」 |
| Docker | `.env.docker` | `docker compose up -d` |
| 源码脚本 | 仓库根目录 `.env` | Ctrl+C 后重跑脚本 |

#### 路径 B：演示专用密钥（解压即用）

若希望评委完全不注册账号，可由参赛者单独申请一个仅用于评审的密钥（建议使用免费额度、赛后吊销），打进离线运行包：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-offline.ps1 -ApiKey "评审专用key"
```

生成的压缩包内已写好 `.env`，评委解压双击「启动.bat」即可使用 AI。

- 该密钥只存在于分发的压缩包中，不进入 Git 仓库
- 分发渠道建议：网盘链接、比赛平台附件、邮件或随附的说明卡
- 密钥泄露或赛程结束后，在供应商后台立即吊销并重建离线包

## 三、未配置密钥时的可用范围

| 功能 | 无密钥 | 有密钥 |
| --- | --- | --- |
| 注册 / 登录 / 个人主页 | 可用 | 可用 |
| 悬浮助手离线问答、页面跳转 | 可用 | 可用 |
| 知识库浏览与检索评测 | 可用 | 可用 |
| Agent 方案生成、迭代、质检 | 不可用 | 可用 |
| 多模态截图理解 | 不可用 | 需额外配置视觉模型 |

未配置时点击生成会提示「未配置任何模型供应商」，属预期行为。

## 四、验证清单

1. 打开 `http://localhost:3000/api/health`，确认 `"textModelConfigured": true`
2. 注册账号（密码 8-20 位，不能纯数字）
3. 进入 `/tool`，点击「填入示例」→「创新合成」
4. 观察 Agent 时间线：需求解析 → 知识检索 → 工具推理 → 方案生成 → 质检
5. 切换「依据 / 质检 / 架构图 / 知识库」标签，查看引用来源、质量评分与架构图
6. 追加补充需求，验证方案迭代
7. 打开「个人主页 → AI 审计」，查看模型路由与 Token 统计

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 生成失败，提示额度不足 | 供应商余额为 0，充值或改用免费模型 |
| 提示密钥无效 | key 复制错误，或修改环境变量后未重启服务 |
| 已填 key 仍提示「未配置任何模型供应商」 | 变量名需与供应商对应（如智谱用 `ZHIPU_API_KEY`），且 `AI_PROVIDER_ORDER` 中的 ID 要在支持列表内（如 `zhipu`） |
| 页面打不开 | 确认 3000 端口未被占用；Docker 方式执行 `docker compose ps` |
| 重启后登录态丢失 | 使用 http 访问非 localhost 地址时，请改用 localhost 或配置 HTTPS |
| 数据想重置 | 删除 `data/dev.db`（Docker 方式删除数据卷）后重启 |

## 六、安全说明

- 仓库中只包含 `.env.example` 模板，不含任何真实密钥
- 两种路径的密钥边界：评委自备密钥只在本机；演示密钥只在分发的离线包内，二者都不进入 Git 仓库
- 离线包预置密钥仅用于评审演示，建议使用免费额度并随时可吊销
- 服务端已启用：注册 IP 限流、单用户调用限流（10 次/分钟、200 次/天）、输入长度上限、未登录接口 401
