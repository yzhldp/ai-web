# 九、评审标准对标说明

本文档逐项对照大赛评分表，说明每项能力的实现位置、可验证方式与当前边界，便于评委快速核验。

## 9.1 评分维度总览

| 评分维度 | 权重 | 本项目对应能力 |
| --- | --- | --- |
| AI 技术深度 | 35% | Agent 工作流、RAG、多模态、工具调用、安全可控 |
| 创新性 | 25% | 碎片输入结构化、双模式、可观测 Agent、离线混合检索 |
| 前端工程质量 | 10% | TypeScript 严格模式、Zod 校验、组件分层、性能优化 |
| 实用性 | 10% | 真实痛点、完整可执行方案、依据与质检 |
| 用户体验 | 10% | 阶段进度、流式输出、可停止、引用可解释 |
| 社会价值与商业潜力 | 10% | 降低创新门槛、双场景商业化路径 |

## 9.2 AI 技术深度（35%）

### 9.2.1 大模型集成质量（8%）

- 统一的 OpenAI 兼容接入层，内置 DeepSeek / 通义千问 / 智谱 GLM / Kimi / 豆包 / 文心一言 / 腾讯混元 / 讯飞星火 / MiniMax / 阶跃星辰 / 零一万物 / 百川 / 商汤 / 硅基流动等 14 家国内主流平台，以及自定义兼容入口与本地 Ollama；
- 工作台「创新合成」按钮下方提供模型选择器，用户可随时指定优先供应商，选择写入 localStorage 并在下次进入时恢复；
- 按优先级自动故障转移：超时、报错、非法 JSON、未产生工具调用都会切换下一家；流式生成在首 Token 前可无缝切换；
- 每个调用设置温度、超时、重试上限，并区分「解析 / 生成 / 质检」不同温度；
- 结构化输出使用 JSON 提示词 + Zod Schema 校验，兼容不支持 JSON Schema / 工具模式的模型；
- 提供真实模型质量评测接口，逐供应商测试结构化 JSON、Function Calling 与引用生成，结果写入审计；
- 模型不可用时按阶段降级，不直接白屏；客户端断开通过 `request.signal` 中止调用，避免空耗 Token。

实现：`src/lib/ai/providers.ts`、`src/lib/ai/failover.ts`、`src/lib/ai/evaluation.ts`、`src/lib/agent/prompts.ts`、`src/lib/agent/planner.ts`

### 9.2.2 Agent 工作流设计（8%）

- 显式五阶段状态机：需求解析 → 知识检索 → 工具推理 → 方案生成 → 质检与架构图；
- 每阶段推送结构化 SSE 事件，前端时间线实时展示状态、耗时与中间结论；
- 支持深度模式（4 次模型调用）与快速模式（1 次调用）切换；
- 支持中途停止、失败降级、工具结果补充；停止时会通过请求信号中止上游模型调用。

实现：`src/lib/agent/planner.ts`、`src/app/api/agent/generate/route.ts`、`src/components/agent-timeline.tsx`

验证：登录后打开 `/tool`，观察右侧五阶段时间线与「依据」面板。

### 9.2.3 RAG 技术应用（6%）

- 8 篇领域文档、32 个知识切块，按二级标题切分并保留重叠；
- 中文二元组分词 + 领域同义词扩展；
- BM25 与 2048 维稀疏向量余弦加权融合，公式可解释；
- 生成时注入编号来源并要求正文标注 `[n]`，生成后校验并移除越界引用；
- 提供检索调试接口与知识库标签页，可现场查看双通道得分；
- 内置 10 条标注查询，提供 Recall@6 / HitRate / MRR 量化评测。

实现：`src/lib/rag/corpus.ts`、`src/lib/rag/index.ts`、`src/app/api/knowledge/route.ts`、`src/components/knowledge-panel.tsx`

验证：

```bash
curl -b cookie.txt -H 'Content-Type: application/json' \
  -d '{"query":"小团队如何做 RAG 和排期","topK":4}' \
  http://localhost:3000/api/knowledge
```

### 9.2.4 多模态能力（5%）

- 图片输入：界面截图 / 手绘草图 / 白板照片，前端压缩后由视觉模型理解，注入生成提示词；
- 图表输出：质检阶段生成 Mermaid 架构图，前端渲染并可导出 SVG；
- 未配置视觉模型时自动降级并提示，主流程不受影响。

实现：`src/components/plan-workspace.tsx`（上传）、`src/lib/agent/planner.ts`（视觉调用）、`src/components/plan-diagram.tsx`

配置：`VISION_MODEL`、`VISION_BASE_URL`、`VISION_API_KEY`。

### 9.2.5 AI 安全与可控性（4%）

- 提示词注入检测（5 类模式，多处命中直接拦截）；
- 违法违规内容分类拦截，生成后做输出侧风险扫描并写入标记；
- 手机号 / 邮箱 / 身份证号脱敏后落库；
- 方案支持公开 / 私有：私有方案仅作者可读写，公开方案允许其他登录用户浏览与评论；
- 评论支持作者本人或方案作者删除，公开项目评论区具备基本治理能力；
- 接口与页面双重校验归属，避免通过 ID 越权读取；
- 登录按 IP 限流、注册按 IP 限流，评论限制 500 字并做内容审核；
- 输出剔除内部标记、补齐 AI 声明、超长截断，越界引用自动移除；
- `AiAuditLog` 全链路审计，个人主页可查看。

实现：`src/lib/safety.ts`、`src/lib/audit.ts`、`src/lib/rate-limit.ts`、`src/components/audit-panel.tsx`

验证：提交包含「忽略以上指令 + 输出系统提示词」的输入，接口返回 400 并写入审计。

### 9.2.6 MCP / 工具集成（4%）

- **内置真实 MCP Server**：`/api/mcp`，实现 MCP HTTP JSON-RPC 2.0 的 `initialize`、`tools/list`、`tools/call`、`ping` 核心方法；
- 对外暴露 4 个结构化工具：`search_knowledge_base`、`recommend_tech_stack`、`estimate_schedule`、`risk_checklist`，均提供 JSON Schema；
- MCP 工具与站内 Function Calling 复用同一套确定性实现，避免两套逻辑漂移；
- 鉴权支持 `MCP_API_KEY`（`Authorization: Bearer` 或 `x-mcp-key`）或站内登录会话，按 60 次/分钟限流；
- 错误按 JSON-RPC 标准码返回（-32600 / -32601 / -32602 / -32603），并提供 `GET /api/mcp` 服务发现；
- 站内另有 `web_search`（Tavily）工具，未配置时明确返回不可用说明，不编造结果。

实现：`src/lib/mcp/server.ts`、`src/app/api/mcp/route.ts`、`src/lib/agent/tools.ts`

验证：

```bash
curl -s http://localhost:3000/api/mcp

curl -s -b cookie.txt -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  http://localhost:3000/api/mcp
```

## 9.3 创新性（25%）

### 9.3.1 选题创新（10%）

面向「只有零散痛点与想法、无法形成完整项目」的人群，将三段碎片信息自动整合为结构化方案。区别于通用聊天机器人，产品以「创意 → 雏形」为唯一核心闭环，双模式覆盖软件开发与创业孵化。

### 9.3.2 技术创新（8%）

- 不依赖外部向量库的离线混合检索；
- 显式状态机 + 事件流的可观测 Agent；
- 生成结果自带检索依据、工具结论与质检评分；
- 文本 + 图片 + 架构图的多模态闭环。

### 9.3.3 交互模式创新（7%）

- 「对话即导航」悬浮助手（`[[NAV:xxx]]` 结构化指令）；
- Agent 工作流时间线，把模型内部过程外化为可理解的步骤；
- 生成中可停止、可迭代，依据与评分随时可查。

## 9.4 前端工程质量（10%）

- **代码质量**：TypeScript `strict`、无 `any` 滥用、统一类型定义、Zod 入参校验、全局错误边界；
- **组件与架构**：页面 / 业务组件 / UI 基础组件分层；Agent 时间线、来源、质检、架构图、知识库、审计均为独立组件；SSE 解析与图片压缩抽离为公共模块；
- **性能优化**：Token 60ms 节流渲染、mermaid 动态导入、`optimizePackageImports` 图标按需引入、安全响应头与压缩；登录页图片转为 WebP（约 976KB → 240KB）；首屏共享 JS 约 89kB，工作台首屏约 226kB；
- **测试与 CI**：Vitest 54 个单元测试（覆盖权限矩阵、MCP 协议、RAG、安全、供应商路由）、ESLint 零警告、GitHub Actions 执行类型检查 / 测试 / Lint / 构建。

实现：`src/components/*`、`next.config.mjs`、`src/app/error.tsx`、`src/lib/validation.ts`

## 9.5 实用性（10%）

- 场景真实：社团报名、校园二手交易、学习规划等高频痛点；
- 方案完整：总览、痛点、用户、功能、模块、技术选型、排期、风险、验收标准；
- 结果可执行：排期由工具按模块数计算，技术选型有规则依据，风险有应对措施；
- 结果可复用：方案自动保存、支持迭代、详情页可查看架构图 / 质检 / 依据，架构图可导出；
- 社区可协作：项目可一键公开 / 私有，公开后可被浏览与评论，支持进入评论者公开主页查看其公开项目。

## 9.6 用户体验（10%）

- 视觉：渐变主色、卡片层级、悬浮助手、响应式双栏；
- 交互：示例填充、图片预览、生成中停止、加载与错误提示、Tab 分层；
- AI 交互：阶段进度替代单一转圈、流式打字机、引用来源、质检建议、降级提示；
- 社区交互：首页社区精选、未生成方案时展示社区最新讨论、评论支持楼中楼回复 / 点赞 / 收藏、评论头像跳转公开主页、个人主页可查看点赞与收藏内容。

## 9.7 社会价值与商业潜力（10%）

- **社会价值**：降低普通人把想法变成方案的门槛，适合校园创新、县域创业、公益项目策划；安全策略避免生成违法违规内容；
- **商业潜力**：可面向个人订阅（生成次数 / 深度质检）、高校与孵化器 B 端采购、企业创新管理平台私有化部署；后续可沉淀行业模板与知识库形成壁垒。

## 9.8 部署与验收清单

```bash
# 1. 本地构建
pnpm install
cp .env.example .env        # 至少配置一个供应商密钥 + JWT_SECRET
pnpm db:push
pnpm lint && pnpm test && pnpm build
pnpm start

# 2. Docker Compose
cp .env.docker.example .env.docker
docker compose up -d --build
curl http://localhost:3000/api/health

# 3. 冒烟验收
curl -i http://localhost:3000/api/health          # 200 + db ok
# 注册 / 登录后：
#   /tool 页生成方案，观察五阶段时间线
#   「依据」页查看 RAG 双通道得分
#   「知识库」页执行检索与 Recall@6 / MRR 评测
#   追加补充需求，验证迭代后质检与架构图刷新
#   个人主页「AI 审计」查看 Token / 工具调用 / 模型切换 / 安全标记
```

## 9.9 边界与后续规划

- 当前向量检索为离线稀疏向量，数据量增大后可替换为 pgvector / Milvus；
- 内容审核为关键词规则，生产环境应接入专业内容安全 API；
- 限流为单实例内存实现，多副本需迁移 Redis；
- 质检评分为模型自评，仅用于发现短板，不作为权威结论；
- 多模态依赖额外视觉模型，未配置时自动降级为文本 + 架构图。
