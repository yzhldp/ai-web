# 十一、评审体验指南

本文档面向评审老师与体验者，说明三种运行方式、AI 功能的启用方法，以及未配置密钥时的可用范围。

---

## 一、三种运行方式（按省事程度排序）

| 方式 | 需要安装 | 首次耗时 | 适用场景 |
| --- | --- | --- | --- |
| A. 在线体验地址 | 无，浏览器打开 | 0 | 有公网环境时最省事 |
| B. 离线运行包（Windows x64） | 无 | 解压后约 10 秒 | 评委本地电脑无 Node / Docker |
| C. Docker Compose | Docker Desktop | 1-3 分钟（拉取预构建镜像） | 已有 Docker 环境 |
| D. 源码一键脚本 | Node.js 18.17+ | 3-5 分钟 | 需要对源码评审或二次开发 |

### 方式 B：离线运行包

1. 解压 `ai-web-offline-win-x64.zip` 到任意目录（路径不含中文和空格）
2. 双击「启动.bat」
3. 浏览器自动打开 http://localhost:3000

包内已内置 Node.js、全部生产依赖与预生成的数据库，无需联网即可打开页面。

### 方式 C：Docker Compose

```bash
cp .env.docker.example .env.docker
docker compose up -d --build
```

或直接拉取预构建镜像（最快）：

```bash
docker compose -f docker-compose.release.yml up -d
```

### 方式 D：源码一键脚本

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

```bash
# macOS / Linux
sh scripts/start-local.sh
```

## 二、AI 功能如何启用

AI 能力由服务端读取模型密钥后启用，密钥不会出现在前端。项目支持 DeepSeek、通义千问、Moonshot、OpenAI 兼容服务与本地 Ollama，按优先级自动故障转移。

### 推荐：免费模型（零成本）

智谱 GLM-4-Flash 永久免费，注册地址 https://open.bigmodel.cn ，创建 API Key 后写入环境变量：

```env
OPENAI_API_KEY="你的智谱key"
OPENAI_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
OPENAI_MODEL="glm-4-flash"
AI_PROVIDER_ORDER="openai"
```

| 运行方式 | 配置文件 | 生效方式 |
| --- | --- | --- |
| 离线运行包 | 解压目录下的 `.env` | 关闭窗口后重新双击「启动.bat」 |
| Docker | `.env.docker` | `docker compose up -d` |
| 源码脚本 | 仓库根目录 `.env` | Ctrl+C 后重跑脚本 |

### 其他可选供应商

```env
# 通义千问
DASHSCOPE_API_KEY="sk-xxx"

# Moonshot
MOONSHOT_API_KEY="sk-xxx"

# DeepSeek（需账户余额）
DEEPSEEK_API_KEY="sk-xxx"

# 本地 Ollama（需先 ollama pull qwen2.5:7b）
OLLAMA_BASE_URL="http://127.0.0.1:11434/v1"
OLLAMA_MODEL="qwen2.5:7b"
```

## 三、未配置密钥时的可用范围

| 功能 | 无密钥 | 有密钥 |
| --- | --- | --- |
| 注册 / 登录 / 个人主页 | 可用 | 可用 |
| 悬浮助手离线问答、页面跳转 | 可用 | 可用 |
| 知识库浏览与检索评测 | 可用 | 可用 |
| Agent 方案生成、迭代、质检 | 不可用 | 可用 |
| 多模态截图理解 | 不可用 | 需额外配置视觉模型 |

未配置时点击生成会提示「未配置任何模型供应商」，属预期行为。

## 四、验证清单

1. 打开 `http://localhost:3000/api/health`，确认 `"textModelConfigured": true`
2. 注册账号（密码 8-20 位，不能纯数字）
3. 进入 `/tool`，点击「填入示例」→「创新合成」
4. 观察 Agent 时间线：需求解析 → 知识检索 → 工具推理 → 方案生成 → 质检
5. 切换「依据 / 质检 / 架构图 / 知识库」标签，查看引用来源、质量评分与架构图
6. 追加补充需求，验证方案迭代
7. 打开「个人主页 → AI 审计」，查看模型路由与 Token 统计

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 生成失败，提示额度不足 | 供应商余额为 0，充值或改用免费模型 |
| 提示密钥无效 | key 复制错误，或修改环境变量后未重启服务 |
| 页面打不开 | 确认 3000 端口未被占用；Docker 方式执行 `docker compose ps` |
| 重启后登录态丢失 | 使用 http 访问非 localhost 地址时，请改用 localhost 或配置 HTTPS |
| 数据想重置 | 删除 `data/dev.db`（Docker 方式删除数据卷）后重启 |

## 六、安全说明

- 仓库中只包含 `.env.example` 模板，不含任何真实密钥
- 离线包预置密钥仅用于评审演示，建议使用免费额度并随时可吊销
- 服务端已启用：注册 IP 限流、单用户调用限流（10 次/分钟、200 次/天）、输入长度上限、未登录接口 401
